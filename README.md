# Lumen Jewelry Studio

> Handmade jewelry website template for custom orders and launch collections.

## Live Demo

See it in action: [https://creatiquemedia.com/templates/lumen-jewelry-studio/demo](https://creatiquemedia.com/templates/lumen-jewelry-studio/demo)

## Who It Is For

Independent jewelry makers, custom engagement artists, and boutique craft brands.

A jewelry-maker template with custom order forms, ring-sizing guidance, collection launches, and gift-focused conversion sections.

## What's Included

**Key sections and features:**

- Custom order intake with sizing and metal options
- Collection drops for seasonal and limited pieces
- Gift and occasion-based merchandising blocks
- Care guide and authenticity trust sections

**Additional features:**

- Custom design intake for stone, metal, style, and budget
- Collection launch blocks with waitlist and sold-out history
- Ring size guidance sections
- Gift paths for anniversary, wedding, and birthday
- Care and warranty details
- Client story proof sections

**Demo page blocks:** Ring Size Guide, Collection Launch Strip, Custom Build Form.

## Design & Tech Highlights

Built with Next.js, React, TypeScript, and Tailwind CSS, with Stripe and PWA support listed in the template stack.
